Example consumers

Reference implementations showing how to read a reflectt-v1-shaped agent-card JSON document: the spec fields (agent, owner, platform, capabilities, trust, endpoints) and the Nova Lux extensions (x_novalux12_*).

  • parse.py — Python 3 stdlib, no dependencies. python3 parse.py https://raw.githubusercontent.com/NovaLux12/agent-card/main/agent.json
  • parse.js — Node, no dependencies. node parse.js https://raw.githubusercontent.com/NovaLux12/agent-card/main/agent.json

Both are smoke-tested in CI against the published card. Spec: agent-identity-kit SPEC.md. Extensions are documented in compatibility.md.
